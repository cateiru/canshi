# 19. うんち記録・嘔吐記録への写真添付

## 目的

`18` の基盤を使い、記録画面から写真を添付・閲覧・削除できる共通 UI を実装し、最初の対象としてうんち記録・嘔吐記録に組み込む。以降の添付 PR（`20`〜`23`）はこの共通 UI を再利用する。

## スコープ

- 添付 UI の共通コンポーネント（`src/features/media/` 配下）
  - `MediaAttachmentField`：記録フォーム内のファイル選択・プレビュー・削除。複数枚に対応する
  - `MediaGallery`：一覧・詳細画面でのサムネイル表示と、タップで元データを表示するモーダル（`04` の `Modal` を利用）
  - `MediaThumbnailStrip`：タイムラインなど小さな領域向けのサムネイル列
  - 添付は「記録を保存してから」ではなく、フォーム上で選択したファイルを保存アクションと同時にアップロードする。新規作成時は記録 ID が確定した後に `18` の API を呼ぶ
- うんち記録・嘔吐記録の新規作成・編集フォームへの組み込み
- うんち記録・嘔吐記録の一覧へのサムネイル表示
- うんち記録・嘔吐記録の削除時に `deleteMediaAssetsByRecord` を呼び、関連メディアを削除する
- タイムライン（`14`）の各エントリにサムネイルを表示する。`record_type` を横断して `media_assets` を引く仕組みにし、`20` 以降の記録種別が追加されても変更不要にする
- E2E テスト（Playwright）：うんち記録に画像を添付し、一覧にサムネイルが表示されるまでを検証する（`docs/idea/index.md` の E2E 対象「画像アップロード」に対応する最初のシナリオ）

## 対象外

- 動画の添付（うんち・嘔吐は写真のみ。動画は `20` の症状記録で対応する）
- 症状・服薬・通院・愛猫の体・ごはん商品への添付（`20`〜`23`）
- AI 補助分類（第3段階、`17`）

## DB マイグレーション

なし（`18` で拡張済みの `media_assets` を利用。`record_type` は `"poop_record"`・`"vomit_record"` を使う）

## 受け入れ条件

- うんち記録・嘔吐記録の新規作成・編集で写真を複数枚添付・削除できる
- 一覧・タイムラインにサムネイルが表示され、タップで元データを閲覧できる
- 記録を削除すると関連する写真が R2 と `media_assets` から削除される
- E2E テストで画像添付から一覧表示までが検証される
