# 20. 症状記録への写真・動画添付

## 目的

症状記録に写真・動画を添付できるようにする。動画添付の最初の対象となる。

## スコープ

- 症状記録の新規作成・編集フォームへの `MediaAttachmentField` の組み込み（画像・動画の両方を許可）
- 動画のサムネイルをブラウザ側で生成し、元データと同時に送信する（`18` の方式）
- 動画のプレビュー再生（`MediaGallery` のモーダル内で `<video controls>` により再生）
- 動画には位置情報などのメタデータが残る可能性がある旨の注意文をフォームに表示する（`18` の制約）
- 症状記録の一覧・タイムラインでのサムネイル表示
- 症状記録の削除時に関連メディアを削除する

## 対象外

- 動画の変換・圧縮（元データをそのまま保存する）
- 動画のメタデータ除去（`18` の対象外事項）

## 依存 PR

- `11`（症状記録）
- `19`（添付 UI 共通コンポーネント）

## 変更・追加内容

- `src/features/media/MediaAttachmentField.tsx` の動画対応（`accept` の切り替え、サムネイル生成）
- `src/features/media/MediaGallery.tsx` の動画再生対応
- `src/features/symptoms/` のフォーム・アクション・クエリの更新
- `src/app/cats/[catId]/symptoms/` の一覧ページの更新

## DB マイグレーション

なし（`record_type` は `"symptom"` を使う）

## 受け入れ条件

- 症状記録に写真・動画を添付・削除できる
- 動画のサムネイルが一覧・タイムラインに表示され、モーダルで再生できる
- 記録を削除すると関連する写真・動画が削除される
