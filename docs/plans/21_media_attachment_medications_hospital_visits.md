# 21. 服薬記録・通院記録への写真添付

## 目的

処方箋・薬袋（服薬記録）、診療明細（通院記録）の写真を添付できるようにする。どちらも「書類の写真」という同じ用途のため 1 PR にまとめる。

## スコープ

- 服薬記録（`medications`）の新規作成・編集フォームへの `MediaAttachmentField` の組み込み
  - 添付対象は服薬の予定・マスタ的な情報である `medications` とし、投薬実績（`medication_doses`）には添付しない
- 通院記録（`hospital_visits`）の新規作成・編集フォームへの組み込み
- 一覧・詳細でのサムネイル表示。書類の写真は文字を読む用途が主のため、モーダルでは元データを等倍で表示し、ピンチ・スクロールで拡大できるようにする
- 服薬記録・通院記録の削除時に関連メディアを削除する
- タイムラインの通院記録エントリへのサムネイル表示（`medication_doses` は添付対象外のため服薬の投薬実績エントリには表示しない）

## 対象外

- 処方箋の文字認識（OCR）や薬名の自動入力
- 動画の添付（書類用途のため写真のみ）

## 依存 PR

- `12`（服薬記録）
- `13`（通院記録）
- `19`（添付 UI 共通コンポーネント）

## 変更・追加内容

- `src/features/medications/`・`src/features/hospital-visits/` のフォーム・アクション・クエリの更新
- `src/app/cats/[catId]/medications/`・`hospital-visits/` の一覧ページの更新
- `src/features/media/MediaGallery.tsx` の等倍表示モードの追加

## DB マイグレーション

なし（`record_type` は `"medication"`・`"hospital_visit"` を使う）

## 受け入れ条件

- 服薬記録・通院記録に写真を添付・削除できる
- 一覧・タイムラインにサムネイルが表示され、モーダルで書類の文字が読める大きさで閲覧できる
- 記録を削除すると関連する写真が削除される
