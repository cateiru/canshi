# 17. 第3段階 概要

第2段階完了後に着手する機能の方向性のみを記載する。PR 単位への詳細分割は別途行う。

## 対象機能

- AI による画像の補助分類
  - `ai_evaluations` テーブルは `03` で用意済みのため、OpenAI API（`docs/idea/index.md` 記載のモデル）を用いた画像分類の呼び出し・結果保存を実装する
  - 対象は、うんち・嘔吐・愛猫の体
  - 食欲・元気・回数・継続時間・血液の有無などの付随情報も入力として利用する
  - 判定不能・低信頼度時は断定せず、動物病院への相談を案内する
  - 利用者による評価結果の修正を可能にする
- 猫ごとの AI 参照用プロフィール・履歴の保持
- 複数猫対応の UI・猫ごとの比較
  - DB は MVP から `cat_id` を持つ設計のため、猫の切り替え UI・複数猫の記録比較画面を追加する

## 想定される分割方針

- AI 呼び出し基盤（プロンプト管理・モデル呼び出し・結果保存・信頼度判定）を 1 PR として独立させ、対象記録種別（うんち・嘔吐・愛猫の体）ごとに UI 統合を分割する
- 猫の複数管理 UI（切り替え・比較画面）は記録機能とは独立した PR とする

- 利用者による修正結果をどのように以降の判定に反映するか（学習には使わない前提でよいか）
