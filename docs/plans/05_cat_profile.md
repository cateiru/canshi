# 05. 猫プロフィール機能

## 目的

猫の基本情報を登録・編集・閲覧できるようにする。以降のすべての記録機能はここで作成した猫を参照する。

## スコープ

- 猫の基本情報（名前、性別、生年月日、猫種、お迎え日）の登録・編集・一覧・詳細表示
- 生年月日から年齢を計算して表示
- お迎え日からの経過日数を計算して表示
- 猫が 0 件の状態（初回利用時）の導線

## 対象外

- 複数猫の切り替え UI・比較（第3段階、`17`）
- 写真の登録（第2段階）
- AI 参照用プロフィール（第3段階）

## 依存 PR

- `03`（DB スキーマ基盤・cats テーブル）
- `04`（デザインシステム）

## 変更・追加内容

- `src/app/cats/` 配下の一覧・詳細・新規作成・編集ページ
- `src/features/cats/`（フォーム・年齢計算・お迎え日数計算などのロジック）
- `cats` テーブルに対する CRUD API（Server Actions もしくは Route Handlers、以降の PR も同じ方式に統一する）

## DB マイグレーション

なし（`03` で作成済みの `cats` テーブルを利用）

## 受け入れ条件

- 猫の新規登録・編集・削除ができる
- 一覧・詳細画面で年齢とお迎え日数が正しく表示される
- 入力値のバリデーション（名前必須、日付の妥当性など）が実装されている
- 主要なロジック（年齢計算・お迎え日数計算）に Vitest の単体テストがある
