# 16. 第2段階 概要

MVP（`01`〜`15`）完了後に着手する機能の方向性を記載する。PR 単位の詳細計画は `18`〜`31` に分割済み。

## 対象機能

- 写真・動画のアップロード
  - `media_assets` テーブルは `03` で用意済みのため、R2 へのアップロード・EXIF 削除・サムネイル生成・Cloudflare Workers 経由の配信（Cloudflare Access によるアクセス確認後）を実装する
  - 対象は、うんち・嘔吐・症状・服薬（処方箋・薬袋）・通院（診療明細）・愛猫の体・ごはん商品（`media_assets.cat_id` は nullable のため、猫に紐付かないごはん商品の画像も同じ仕組みで扱える）
  - アップロードサイズ・保存容量の上限設定
  - 記録削除時の関連画像・動画の削除
- 水の記録
  - 測定方法、給水量、残量、こぼれ・水交換の有無
  - 給水量と残量からの推定飲水量の計算
  - 主観評価（多い・いつも通り・少ない）
- シャンプー記録
  - 実施日の記録
- 掃除記録
  - 掃除対象・頻度の設定と実施日の記録
- PWA 対応
- Web Push 通知
  - 誕生日・月齢・年齢の節目、シャンプー経過月数、体重測定の提案、掃除タイミングなどの通知
  - 通知時刻・タイムゾーンの設定、既読・重複防止、完了・延期・無視、通知ごとの有効・無効
  - Web Push 非対応環境向けの通知センター表示

## PR 分割

各 PR の詳細は次のファイルを参照。依存関係は `00` の PR 一覧に記載する。

- メディア
  - `18` メディアアップロード基盤（R2 連携・EXIF 削除・サムネイル生成・配信・上限・削除）
  - `19` うんち記録・嘔吐記録への写真添付（添付 UI 共通コンポーネント・タイムラインのサムネイル表示を含む）
  - `20` 症状記録への写真・動画添付（動画の最初の対象）
  - `21` 服薬記録・通院記録への写真添付（処方箋・薬袋・診療明細）
  - `22` 愛猫の体の写真とプロフィール画像
  - `23` ごはん商品の画像（猫に紐付かないメディアの最初の対象）
- 記録
  - `24` 水の記録機能
  - `25` シャンプー記録機能
  - `26` 掃除記録機能
- PWA・通知
  - `27` PWA 対応
  - `28` 通知条件の判定ロジック
  - `29` Web Push 送信基盤（Cloudflare Workflows のスケジュール実行）
  - `30` 通知センター UI
  - `31` 通知設定 UI

添付 UI は原則として記録種別ごとに分割するが、うんち・嘔吐（同一構造の写真添付）と服薬・通院（書類の写真）は用途が同じため 1 PR にまとめている。

## 着手順の目安

- `18` → `19` → `20`〜`23`（`19` 完了後は互いに独立して着手できる）
- `24`〜`26` は `18`〜`23` と独立して着手できる
- `27` は独立して着手できる
- `28` は `25`・`26` の後、`29` は `27`・`28` の後、`30` は `28` の後、`31` は `29`・`30` の後

## 未決定事項の暫定決定

`18` の着手前に確認が必要だった事項は次のとおり暫定値を置いた。変更する場合は `18` の着手前に `18` の計画書を更新する。

- 1 ファイルあたりの上限：画像 10 MB、動画 100 MB（環境変数で上書き可能）
- 保存容量の上限：合計 10 GB（R2 の無料枠を基準。環境変数で上書き可能）
- サムネイル生成：Workers 上でアップロード時に同期生成する。個人・家庭内利用の規模では Workflows によるバッチ処理の複雑さに見合わないため。動画はブラウザ側で先頭フレームを切り出して送信する
