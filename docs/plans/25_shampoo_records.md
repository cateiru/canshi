# 25. シャンプー記録機能

## 目的

シャンプーの実施日を記録し、前回からの経過日数を把握できるようにする。`28` の通知（前回のシャンプーから指定した月数が経過）の判定元になる。

## スコープ

- 実施日時と備考の記録
- 記録の一覧・編集・削除
- 一覧の先頭に「前回のシャンプーからの経過日数」を表示
- 猫詳細ページの記録導線（`RECORD_NAV_ITEMS`）への追加
- タイムライン（`14`）への追加（`03` の発生日時列の対応表に `shampoo_records.performed_at` を追加する）

## 対象外

- シャンプー経過月数の通知（`28`・`31`）
- 使用したシャンプー製品の管理

## 依存 PR

- `03`（DB スキーマ基盤）
- `04`（デザインシステム）
- `05`（猫プロフィール）
- `14`（タイムライン）

## 変更・追加内容

- `shampoo_records` テーブル
- `src/app/cats/[catId]/shampoo-records/` 配下のページ
- `src/features/shampoo-records/`（経過日数の計算ロジック）
- `src/features/cats/recordNav.ts`・`src/features/timeline/` の更新
- `src/db/README.md` の発生日時列の対応表の更新

## DB マイグレーション

- `shampoo_records` テーブルを新規作成
  - `id`、`cat_id`、`performed_at`、`memo`、`created_at`、`updated_at`

## 受け入れ条件

- シャンプー記録の登録・編集・削除・一覧ができる
- 前回のシャンプーからの経過日数が表示される
- タイムラインにシャンプー記録が表示され、種類で絞り込める
- 経過日数の計算ロジックに Vitest の単体テストがある
