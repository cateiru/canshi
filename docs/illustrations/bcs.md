# BCS イラストの依頼文

体重記録フォームの BCS（ボディコンディションスコア）入力で使うイラストを、画像生成 AI（GPT-6-Astra）に依頼するための文面をまとめる。

`public/images/bcs/` に透過 PNG 8 枚を配置済み。暫定の簡易 SVG は差し替え済み。

内蔵の `image_gen` で BCS 3 を最初に生成し、残りの画像はその画像を参照して画風と構図を揃えた。
上から見るガイドは、点線の楕円が腰のくびれを囲むように追加で修正した。
BCS 3 の上面図は、[参考画像の BCS 3](https://storage.googleapis.com/studio-cms-assets/projects/YPqr2D8mq5/s-1350x896_v-fms_webp_66989497-388d-4bf6-b3f2-d93252d0c611.webp) に合わせ、胸からお尻までなだらかにつながる浅いくびれに調整した。
同じ体型を使う肋骨・上面のガイドも揃え、BCS 4 の上面図は BCS 3 より胴体がふっくら見えるよう調整した。
さらに参考画像の各段階と比較し、BCS 1・2 の極端な細さを抑え、全段階の胸から腹部へ続く輪郭を調整した。
横向きの腹部は全体を深くえぐらず、後ろ脚手前のくぼみと皮膚のたるみで段階差を表現する。BCS 4・5 の下腹部は胴体に連続させ、独立した丸い袋の形にしない。横から見るガイドも修正後の BCS 3 に揃えた。
生成後は透過を維持し、縦横比を保ったまま表のサイズに整えた。
実際に使用したプロンプトと追加の修正指示は [bcs-prompts.json](bcs-prompts.json) に記録している。

## 依頼文

以下をそのまま GPT-6-Astra に渡す。1 枚ずつ生成する場合は「共通の指定」と、該当する画像の指定を組み合わせて渡す。

### 共通の指定

```text
猫の体型管理アプリで使う説明用イラストを描いてください。

【共通のスタイル】
- シンプルでやさしいフラットイラスト。線は太めの丸い線（濃紺 #2e3142）、塗りは淡いオレンジベージュ（#f6d3b4）の単色。
- 強調したい部分だけアクセントのオレンジ（#ec995a）の点線で囲む。それ以外の色は使わない。
- 猫は特定の品種に寄せない、短毛の一般的な猫。模様・表情・小物は描かない。
- 背景は透過（透明）。影・グラデーション・テクスチャは付けない。
- 文字・数字・ラベルは画像の中に一切入れない（アプリ側で表示するため）。
- 8 枚すべてで、猫の大きさ・線の太さ・色・画風を完全に揃える。
- 医学的に誇張しすぎず、飼い主が自分の猫と見比べやすい写実寄りのシルエットにする。
- 出力は PNG。

【体型の基準（環境省「飼い主のためのペットフード・ガイドライン」の猫の BCS）】
- BCS 1 痩せ: 肋骨・腰椎・骨盤が外から容易に見える。首が細く、上から見て腰が深くくびれている。横から見て腹部の吊り上がりが顕著。脇腹のひだには脂肪がないか、ひだ自体がない。
- BCS 2 やや痩せ: 背骨と肋骨が容易に触れる。上から見て腰のくびれは最小。横から見て腹部の吊り上がりはわずか。
- BCS 3 理想体重: 肋骨は触れるが、見ることはできない。上から見て肋骨の後ろに腰のくびれがわずかに見られる。横から見て腹部の吊り上がり、脇腹にひだがある。
- BCS 4 やや肥満: 肋骨の上に脂肪がわずかに沈着するが、肋骨は容易に触れる。横から見て腹部の吊り上がりはやや丸くなり、脇腹は窪んでいる。脇腹のひだは適量の脂肪で垂れ下がる。
- BCS 5 肥満: 肋骨や背骨は厚い脂肪におおわれて容易に触れない。横から見て腹部の吊り上がりは丸く、上から見て腰のくびれはほとんど見られない。脇腹のひだが目立つ。
```

### 体型の画像（`bcs-1.png`〜`bcs-5.png`）

```text
【構図】840 × 840 px の正方形。上半分に「真上から見た猫」、下半分に「真横から見た立ち姿の猫」を 1 匹ずつ描く。
- どちらも頭を左、しっぽを右に向ける。
- 上から見た図は、胸・腰のくびれ・お尻の幅の違いが分かるように、体の輪郭をはっきり描く。
- BCS 3 の上面図は、胸からお尻までなだらかにつなぎ、腰のくびれを浅くする。胸・腰・お尻が別々に膨らむ輪郭や、痩せた砂時計型にしない。肋骨・上面のガイドにも同じ体型を使う。
- BCS 1・2 の上面図も胴体中央を極端に細くしない。参考画像の各段階を見比べ、BCS 1 は控えめな骨の表現と腰のくびれ、BCS 2 は BCS 3 より少し細い胴体で違いを表現する。
- 横から見た図は、4 本足で立った姿勢。胸からお腹、後ろ足の付け根にかけてのお腹のライン（吊り上がり）が分かるように描く。
- 横向きの胸から腹部までは厚みを保ち、後ろ脚手前のくぼみを描く。BCS 3 はお腹全体が深いアーチにならないようにする。BCS 4・5 は胸と腹部の両方に厚みを持たせ、下腹部のたるみを独立した丸い袋にしない。
- 5 段階の画像を横に並べたとき、体型以外（頭の大きさ・足の長さ・位置）が一致するようにする。

この構図で、BCS {1〜5 のいずれか}（{痩せ／やや痩せ／理想体重／やや肥満／肥満}）の猫を、上記の体型の基準どおりに描いてください。
```

5 枚それぞれ、最後の 1 文の `{}` を置き換えて生成する。

### 見方 1: 肋骨を触る（`bcs-guide-ribs.png`）

```text
【構図】840 × 512 px の横長。真上から見た BCS 3 の猫（頭を左）の背中から脇腹にかけて、人の手のひらをそっと乗せて撫でている様子を描く。
- 手は猫と同じ線・塗りのシンプルな表現にする（肌色は使わず、白い塗りに濃紺の線）。
- 手の動く方向（頭側からお尻側へ）をアクセントのオレンジの点線の矢印で示す。
- 手の下に、肋骨の位置がうっすら分かる細い線を 3 本ほど描く。
```

```text
【構図】840 × 512 px の横長。真上から見た BCS 3 の猫（頭を左、しっぽを右）を描く。
- 肋骨の後ろにある腰のくびれの部分を、アクセントのオレンジの点線の楕円で囲んで強調する。
```

```text
【構図】840 × 512 px の横長。真横から見た、4 本足で立つ BCS 3 の猫（頭を左、しっぽを右）を描く。
- 胸から後ろ足の付け根にかけてのお腹のライン（吊り上がり）を、アクセントのオレンジの点線の楕円で囲んで強調する。
- 脇腹にわずかなひだ（たるんだ皮膚）があることが分かるように描く。
```

## 差し替え手順

1. 生成した画像を上の表のファイル名で `public/images/bcs/` に置く。
2. 必要に応じて WebP に変換する（その場合は拡張子を `.webp` にそろえる）。
3. `src/features/weight-records/bcsIllustrations.ts` の `BCS_ILLUSTRATION_EXT` を `"png"`（または `"webp"`）に変更する。
4. 形式を変更した場合は、使わなくなった旧画像を削除する。
5. 体重記録フォーム（`/cats/{catId}/weight-records/new`）を開き、スマートフォン幅と PC 幅で表示を確認する。
